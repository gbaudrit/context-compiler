# Context Compiler Studio

Studio statique pour generer facilement :

- `ctxc.config.json`
- la configuration Excel exploitable dans `options.excel`

## Usage

Ouvrir `index.html` dans un navigateur.

Le studio permet :

- de remplir les principales sections du schema coeur
- de generer une configuration Excel conforme au schema du reader Excel
- de copier ou telecharger les JSON generes

## Schemas cibles

- `schemas/core/v0.0.1/ctxc.config.schema.json`
- `schemas/plugin.readers.excel/v0.0.1/ctxc.config.schema.json`
