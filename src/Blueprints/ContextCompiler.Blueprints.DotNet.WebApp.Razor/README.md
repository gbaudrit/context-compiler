# ContextCompiler.Blueprints.DotNet.WebApp.Razor

`ContextCompiler.Blueprints.DotNet.WebApp.Razor` bundles the standard ContextCompiler packs and the .NET-specific modules needed to prepare context for Razor web applications.

## Includes

- `ContextCompiler.Packs.Starter.Standard`
- `ContextCompiler.Modules.Engineering.DotNet`
- `ContextCompiler.Modules.Personas.Developers.DotNet`
- `ContextCompiler.Modules.Prompt.Templates.Scriban`

## Use when

Use this blueprint when you want a ready-to-use ContextCompiler setup for an ASP.NET Core Razor web application.
