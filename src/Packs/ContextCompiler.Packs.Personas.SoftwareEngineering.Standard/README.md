# Standard software engineering personas pack

`ContextCompiler.Packs.Personas.SoftwareEngineering.Standard` bundles the standard software engineering personas for ContextCompiler.

Included modules:

- `ContextCompiler.Modules.Personas.Analysts.Business`
- `ContextCompiler.Modules.Personas.Testers.Analyst`

Use this pack when you want default analysis and testing personas without language-specific developer personas.
