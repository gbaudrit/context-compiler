# Standard prompt pack

`ContextCompiler.Packs.Prompt.Standard` bundles the recommended prompt composer modules for ContextCompiler.

Included modules:

- `ContextCompiler.Modules.Prompt.Composers.Assumptions`
- `ContextCompiler.Modules.Prompt.Composers.Audiences`
- `ContextCompiler.Modules.Prompt.Composers.Constraints`
- `ContextCompiler.Modules.Prompt.Composers.General`
- `ContextCompiler.Modules.Prompt.Composers.Glossary`
- `ContextCompiler.Modules.Prompt.Composers.Objectives`
- `ContextCompiler.Modules.Prompt.Composers.Views`

Use this pack when you want the standard prompt composition experience.
