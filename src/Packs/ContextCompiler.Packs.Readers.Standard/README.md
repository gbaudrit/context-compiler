# Standard readers pack

`ContextCompiler.Packs.Readers.Standard` bundles the standard reader modules for ContextCompiler.

Included modules:

- `ContextCompiler.Modules.Readers.Excel`
- `ContextCompiler.Modules.Readers.Markdown`
- `ContextCompiler.Modules.Readers.PDF`
- `ContextCompiler.Modules.Readers.Text`
- `ContextCompiler.Modules.Readers.Yaml`

Use this pack when you want support for the most common input formats.
