# Standard readers pack

`ContextCompiler.Readers.Packs.Standard` bundles the standard reader modules for ContextCompiler.

Included modules:

- `ContextCompiler.Readers.Modules.Excel`
- `ContextCompiler.Readers.Modules.Markdown`
- `ContextCompiler.Readers.Modules.Pdf`
- `ContextCompiler.Readers.Modules.Text`
- `ContextCompiler.Readers.Modules.Yaml`

Use this pack when you want support for the most common input formats.
