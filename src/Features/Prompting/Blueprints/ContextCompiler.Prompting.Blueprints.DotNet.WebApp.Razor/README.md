# ContextCompiler.Prompting.Blueprints.DotNet.WebApp.Razor

`ContextCompiler.Prompting.Blueprints.DotNet.WebApp.Razor` bundles the standard ContextCompiler packs and the .NET-specific modules needed to prepare context for Razor web applications.

## Includes

- `ContextCompiler.Packs.Starter.Standard`
- `ContextCompiler.Prompting.Modules.Engineering.DotNet`
- `ContextCompiler.Prompting.Modules.Personas.Developers.DotNet`
- `ContextCompiler.Prompting.Modules.Templates.Scriban`

## Use when

Use this blueprint when you want a ready-to-use ContextCompiler setup for an ASP.NET Core Razor web application.
