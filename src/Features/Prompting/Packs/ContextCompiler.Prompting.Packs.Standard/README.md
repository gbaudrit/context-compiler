# Standard prompt pack

`ContextCompiler.Prompting.Packs.Standard` bundles the recommended prompt composer modules for ContextCompiler.

Included modules:

- `ContextCompiler.Prompting.Modules.Composers.Assumptions`
- `ContextCompiler.Prompting.Modules.Composers.Audiences`
- `ContextCompiler.Prompting.Modules.Composers.Constraints`
- `ContextCompiler.Prompting.Modules.Composers.General`
- `ContextCompiler.Prompting.Modules.Composers.Glossary`
- `ContextCompiler.Prompting.Modules.Composers.Objectives`
- `ContextCompiler.Prompting.Modules.Composers.Views`

Use this pack when you want the standard prompt composition experience.
