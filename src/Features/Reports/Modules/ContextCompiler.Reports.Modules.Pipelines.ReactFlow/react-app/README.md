# React Flow Pipeline Viewer

Interactive pipeline visualization built with React Flow and ELK.js.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The built files will be in the `dist/` directory.

## Stack

- React 18
- TypeScript
- React Flow 11
- ELK.js
- Zustand
- Vite 6
